[h1]Flyer Dive & Take-off: Balance[/h1]

An optional submod for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3840651516]Flyer Dive & Take-off[/url]. It carries the two balance changes that used to be part of the main mod.

[h2]What it changes[/h2]
[list]
[*][b]Breath attacks while engaged.[/b] Flying units can use their Breath abilities while engaged in melee and while grounded (20 abilities the base game blocks in melee, for example Star Dragon's Breath, Frost Breath and Noxious Breath).
[*][b]Lighter large flyers.[/b] Large flyers have 15 % less mass and the largest flyers 25 % less, so a crowd slows them down more. Exceptions: the Celestial Lion and The Wise One count as large (15 %); flying war machines and chariots keep their mass (Thunderbarges, Sky-junk, Sky Lantern, Skycutters, Burning Chariot, Gyrocopter, Gyrobomber).
[/list]

[h2]Requirements[/h2]
[list]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3840651516]Flyer Dive & Take-off[/url] (required). This submod is built from the same build as the main mod and only works together with it. Update both together; if their versions differ, the battle log ld_flyer_dive.txt says so.
[/list]

[h2]Load order[/h2]
No manual step: enable both mods in the launcher. This submod's file and table names sort before the main mod's; the game uses the rows of the pack whose name sorts first, so its values are the ones that apply.

[h2]Compatibility[/h2]
Mods that ship their own breath ability usage table or overwrite the same flying unit rows win or lose by load order.
